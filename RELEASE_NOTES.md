# Release Notes

## BoxBurnSuplements 1.0.0 (2025-06-20)

### 🚀 Highlights
- Initial public release of BoxBurnSuplements iOS app
- Clean Architecture (Domain, Data, Presentation layers)
- SOLID principles and modular, testable code
- Modern SwiftUI UI with Amazon-like experience
- Combine for reactive data flow
- Mock and real supplement repositories
- Dynamic category and supplement loading from JSON
- Favorites, cart, and checkout flows
- Side menu and tab navigation
- Localization (PT-BR default, easy to extend)
- 80%+ unit test coverage using SwiftTesting
- Comprehensive documentation, changelog, and test specs

### 🛠️ Improvements & Fixes
- Robust error handling for data loading
- Async/await and Combine publisher support in tests
- Refactored navigation and state management for smooth UX

### 📚 Documentation
- README, CHANGELOG, TESTS, and DOCUMENTATION files included
- Architecture, setup, extensibility, and contribution guidelines
